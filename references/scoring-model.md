## 一、维度与权重定稿

| 维度 | 权重 | 说明 |
|---|---|---|
| **需求侧**（客流 + 客群规模） | 40 | 选址核心是"有没有人来吃" |
| **位置侧**（可达性 + 可见性） | 25 | |
| **竞争侧**（密度 + 强度） | 20 | |
| **财务侧**（租金安全垫 + 回本压力） | 15 | |
| **合计** | 100 | |

### 指标 → 权重 → 分段打分规则

#### 维度 1：需求侧（40 分）

| 指标 | 权重 | 分段打分规则 |
|---|---|---|
| 午高峰预期日单量 | 15 | ≥60 单 = 15 / 40–59 = 11 / 25–39 = 7 / <25 = 3 / 缺 = 0 |
| 晚高峰预期日单量 | 15 | ≥72 单 = 15 / 48–71 = 11 / 30–47 = 7 / <30 = 3 / 缺 = 0 |
| 500m 家庭户数 | 10 | ≥3000 户 = 10 / 1500–2999 = 7 / 800–1499 = 4 / <800 = 1 / 缺 = 0 |

#### 维度 2：位置侧（25 分）

| 指标 | 权重 | 分段打分规则 |
|---|---|---|
| 最近地铁距离 | 10 | ≤200m = 10 / 201–400m = 7 / 401–600m = 4 / >600m = 1 / 无地铁 = 0 |
| 动线可达性 | 10 | 地铁直连 = 10 / 绕行 ≤100m = 7 / 绕行 >100m = 3 / 无地铁 = 2 |
| 主干道可见性 | 5 | 临主干道且有门头 = 5 / 临主干道无展示 = 2 / 不临主干道 = 1 |

#### 维度 3：竞争侧（20 分）

| 指标 | 权重 | 分段打分规则 |
|---|---|---|
| 同品类门店密度 | 10 | 0–1 家 = 10 / 2–3 家 = 7 / 4–6 家 = 4 / ≥7 家 = 1 / 0 家（需求未验证）= 6 |
| 竞品强度 | 10 | ≥7 = 10 / 5–6.9 = 6 / 3–4.9 = 3 / <3 = 1 / 无竞品 = 7 |

#### 维度 4：财务侧（15 分）

| 指标 | 权重 | 分段打分规则 |
|---|---|---|
| 租金占营收比 | 10 | ≤15% = 10 / 16–22% = 7 / 23–30% = 4 / >30% = 1 / 缺 = 0 |
| 盈亏单量达成率 | 5 | ≥1.5 = 5 / 1.2–1.49 = 3 / 1.0–1.19 = 1 / <1.0 = 0 |

## 二、总分 → 结论映射 + 置信度

### 总分结论映射

| 总分 | 结论 | 建议 |
|---|---|---|
| ≥ 80 | ✅ 建议开 | 核心指标均达标，竞品压力可控，财务安全垫充足 |
| 60 – 79 | ⚠️ 谨慎 | 有短板，建议补足信息后二次评估 |
| < 60 | ❌ 不建议 | 至少一个核心维度严重不达标 |

### 四档置信度

| 置信度 | 条件 | 含义 |
|---|---|---|
| **A 完整** | 蹲点客流 + 月租金 + 动线 三项全有 | 所有维度正常计分 |
| **B 缺客流** | 未填蹲点客流 | 需求侧 30 分按商圈经验区间估算 |
| **C 缺租金** | 未填月租金 | 财务侧 15 分按参数卡中位数估算 |
| **D 双缺** | 客流 + 租金都未填 | 仅用 POI + 竞品数据评估，"仅作参考" |
