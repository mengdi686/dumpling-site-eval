# 饺子馆选址评估 · 示例运行说明

## 本地直接双击运行
1. 用现代浏览器（Chrome / Edge）打开 `scripts/assess.html`
2. 选择 Mock 数据源（默认）
3. 点页面顶部的示例按钮 ①②③④ 快速载入合成数据
4. 点「🚀 开始评估」
5. 报告生成后点「⬇ 下载报告 HTML」保存

## 通过本地 HTTP server（推荐，避免 file:// 安全限制）
```powershell
powershell -ExecutionPolicy Bypass -File _server.ps1
# 然后浏览器打开 http://localhost:8765/
```

## 四个合成示例（Basic Mock）

| # | 场景 | 预期总分 | 结论 | 说明 |
|---|------|---------|------|------|
| ① | 社区旺铺·高分 | ~90 | ✅ 建议开 | 有租金 + 有客流 + 地铁近 + 社区密集 |
| ② | 商圈中等·谨慎 | ~75 | ⚠️ 谨慎 | 有租金 + 有客流 + 竞争多租金偏高 |
| ③ | 偏远冷门·不建议 | ~60 | ⚠️ 谨慎 | 有租金 + 客流少 + 无地铁 + 无竞品 |
| ④ | 缺客流·置信度B | ~75 | ⚠️ 谨慎 | 无租金 + 无客流 → 财务未纳入 + 需求侧估算 |

## 三个结论都能出现
- ✅ 建议开：示例① 提供足够租金和客流时
- ⚠️ 谨慎：示例②③④
- ❌ 不建议：当坐标位于完全无居住/无餐饮的偏远 + 无租金 + 无客流（Basic 模式下需要手动在表单里清空租金和客流字段）

## 真实 API
在页面顶部的数据源选择器里切换到高德/百度，填入 Key。缺 Key 时自动回落 Mock。
